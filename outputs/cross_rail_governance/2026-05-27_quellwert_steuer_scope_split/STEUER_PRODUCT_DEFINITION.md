## Definition

The Steuer/Kanzlei Rollforward product is a local, deterministic, Excel-first workflow helper. It supports workbook inspection, rollforward, KAP mapping, controlled writeback on copies, `_Pruefstatus`, `_Punkteliste`, publish checks, and Excel integrity verification.

It is not an AI product and not an LLM product.

## What Vega Means Here

`Vega` means only the external project/coding/governance assistant role used in our workspace to:

- read and route context,
- write code or docs when asked,
- run local verifiers,
- create audit bundles,
- update project memory,
- enforce gates and stop rules.

Vega is not part of the tax runtime, not a tax module, not a tax logic engine, and not a tax decision-maker.

## Product Runtime Policy

- No cloud LLM processing.
- No local LLM tax decisions.
- No autonomous tax interpretation.
- No OCR in the current MVP scope.
- No DATEV integration in the current MVP scope.
- No final tax output without human professional review.
- No real client/person data in repo, chat, or ungated provider paths.
- No writing into original Excel files; only copies/outputs.
