## Lessons for Decision Engine / Guards

- Do not calibrate long-horizon rules from this run yet: only 1D outcomes are complete; 5D/10D/20D/60D remain immature.
- Keep manual_review conservative where ticker-specific KPI coverage is missing; early positive returns can be missed opportunities but are not enough to loosen guards.
- Semiconductor and memory names should be watched closely because short-term post-report moves can be large; calibration should separate momentum/technical risk from fundamental evidence quality.
- Tactical Trim / Tactical Underweight should be judged on both absolute weakness and benchmark-relative weakness once 20D/60D windows mature.
- Passed false positives should be revisited after at least 5D and 20D complete; 1D noise is useful as a smoke signal, not a final calibration truth.
