# Obsidian Media Note Policy

Status: memory policy  
Applies to: media notes created from Whisper / YouTube Watcher patterns

## Core Rule

Media ingest must not create a second memory layer beside Obsidian. Draft notes may exist, but durable project truth must go through the Obsidian Memory Promotion Map.

## Allowed Writes

- Draft/source note for owned or permitted material.
- Temporary run note inside a project-local ingest folder.
- Candidate summary that clearly says `draft`, `source_note` or `evidence_candidate`.
- Promotion proposal that links to transcript metadata and review status.

## Forbidden Writes

- Global Obsidian memory update without Gate.
- Overwriting existing project truth from transcript material.
- Storing sensitive transcript content in Backbone without Operator-Go.
- Storing full third-party transcripts when rights are unclear.
- Treating transcript text as a confirmed project rule or fact without promotion.

## Promotion Rule

Promotion to Project Memory or Backbone requires:

- source allowed
- rights status acceptable
- claim verified where needed
- Vivi Review or Operator-Go
- evidence artifacts linked
- no secret/private data leakage

## Note Structure

Recommended draft note sections:

- source metadata
- transcript status
- short summary
- candidate claims
- verification needs
- rights/use notes
- promotion decision

## Acceptance

Obsidian integration is safe when media outputs remain drafts or source notes until reviewed, and durable truth is written only through the existing Backbone promotion path.
