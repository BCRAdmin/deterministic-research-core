## Boundary

This package extracts patterns from reviewed external skills. It installs nothing and grants no new runtime authority.

Blocked by default:

- external skill installation
- API Gateway runtime
- Desktop Control runtime
- Proactive full-autonomy runtime
- phone-home scanner
- silent updater
- second memory layer beside Obsidian

## Use

Use this package when reviewing external skills, repos, agent packages, skill hubs, plugin bundles or self-improving/proactive-agent proposals.

Output should be SOP, playbook, review checklist, sandbox proposal or rejection unless a separate Operator Gate explicitly opens a runtime implementation path.
